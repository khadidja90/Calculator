# 🌿 Interactive Calculator

A modern, responsive calculator built using **HTML, CSS, and vanilla JavaScript**. This project focuses on a clean user interface, accessible interactions, and accurate mathematical expression evaluation without external libraries or frameworks.


##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

##  Keyboard Shortcuts

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `+`, `-`, `*`, `/` | Enter operators |
| `.` | Enter a decimal point |
| `(`, `)` | Group expressions |
| `Enter` or `=` | Calculate the result |
| `Backspace` | Delete the last character |
| `Escape` or `Delete` | Clear the calculator |

##  Implementation Highlights

- **DOM manipulation:** Updates the display dynamically as the user interacts with the calculator.
- **Event delegation:** Handles button clicks through a single event listener.
- **Recursive-descent parser:** Evaluates expressions while respecting operator precedence and parentheses.
- **Input validation:** Rejects unsupported characters and malformed expressions.
- **Separation of concerns:** Keeps the HTML structure, CSS styling, and JavaScript logic in separate files.

The expression evaluator does not rely on JavaScript's `eval()` function.

##  Project Objective

The goal of this project is to practice core frontend development skills, including semantic HTML, responsive CSS, DOM manipulation, event handling, keyboard interactions, and mathematical expression parsing.
